TO-DO LIST APPLICATION USING PYTHON

1. Introduction

The To-Do List Application is a simple Python-based project used to manage daily tasks. It allows users to add new tasks, view existing tasks, mark tasks as completed, and delete unwanted tasks.

2. Aim

To develop a menu-driven task management application using Python programming concepts.

3. Problem Statement

To create a program that manages a list of tasks and stores them in a file. Each task has a task number, title, and status. New tasks are marked as Pending by default.

4. Software Requirements

- Programming Language: Python 3
- Code Editor: Visual Studio Code
- Storage: Text file (todo.txt)
- Operating System: Windows

5. Features

1. Add new tasks.
2. View all tasks.
3. Mark tasks as completed.
4. Delete tasks.
5. Save tasks in a text file.
6. Load saved tasks when the program starts.
7. Handle empty tasks and invalid task numbers.

6. Working of the Project

First, the program loads previously saved tasks from the file. It then displays a menu to the user. The user selects an operation by entering a number. The program performs the selected operation and saves the changes to the file. The menu continues until the user selects Exit.

7. Advantages

- Easy to use.
- Helps organize daily work.
- Saves tasks permanently in a file.
- Reduces the chance of forgetting tasks.
- Demonstrates basic Python programming concepts.

8. Limitations

- The application works through a text-based menu.
- Tasks are stored locally in a text file.
- It does not provide reminders or multiple-user support.

9. Conclusion

The To-Do List Application demonstrates the use of Python lists, dictionaries, functions, loops, conditional statements, and file handling. It provides a simple and useful way to manage daily tasks.
